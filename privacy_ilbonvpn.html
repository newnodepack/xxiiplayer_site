🔒 Privacy Policy

IlbonVPN Extension  |  Last updated: June 2026

📋 1. Overview

This Privacy Policy describes how the IlbonVPN Extension ("Extension", "we", "our") handles user data. This Extension is a Chrome browser extension that provides secure VPN/proxy connection services to users.

We are fully committed to protecting your privacy. This policy explicitly explains what data is processed, the purpose of processing, how it is stored, and our strict non-sharing practices to ensure compliance with the Chrome Web Store Developer Program Policies.

📦 2. Data We Process (Collection)

We process only the minimum necessary data to provide core authentication and proxy routing functionalities.

Chrome Web Store Category Specific Data Types Processed Storage Location
Authentication Information User credentials, passwords, Firebase UID, session tokens Yes Firebase Authentication (Google Server) & Encrypted Local Storage
Personal Communications Email address (used for user account identification) Yes Firebase Authentication Server
Location IP address, country/region (to route proxy traffic) Yes (Ephemeral) Processed in real-time memory (Never written to logs/disk)
Web History Visited URLs, page titles, and timestamps of proxy requests Yes (Ephemeral) Processed instantly through Chrome Proxy API (Zero-Logs)

⚙️ 3. Data Processing & Usage

The collected data categories are used strictly for the following purposes:

  • Authentication Information & Personal Communications (Email): Processed exclusively to manage user registration, secure login sessions, token verification via Firebase, and to verify premium subscription status. We do not use this data for marketing or profiling.
  • Location (IP Address & Region): Processed dynamically to detect your current connection state, optimize routing pathing, and establish a secure tunnel to our Japan proxy nodes.
  • Web History (Visited URLs & Timestamps): Required technically by the chrome.proxy API to forward your network requests through the VPN server. This data is handled strictly in transient memory.

🛡️ 4. Zero-Logs Policy & Security

While Location (IP) and Web History are technically processed to perform the VPN proxy routing, we enforce a strict Zero-Logs Policy:

  • We do NOT inspect, analyze, or manipulate the contents of your web history or traffic.
  • We do NOT record, log, or save your visited URLs, timestamps, or original IP addresses onto any persistent disks or databases. Everything is cleared from real-time memory instantly upon routing execution.
  • All runtime dependencies and SDKs (including Firebase) are securely bundled locally inside the extension package to avoid remote code execution risk.

🚫 5. Data We Do NOT Collect

The following categories of sensitive user data are never processed, collected, or transmitted under any circumstances:

Financial Info Health / Biometric Data User Chat/SMS Content Keystrokes / Form Inputs Device Hardware Serial Numbers Cookies from other sites

We do not sell, trade, lease, or share your personal data, web history, or location details with any third-party advertisers, brokers, or external analytics tracking networks.

👤 8. Your Privacy Rights

You possess full autonomy over your data:

  • Right to Deletion: You can completely erase your account and associated authentication data instantly via the Account panel inside the Extension popup.
  • Right to Opt-Out: You can stop all data processing immediately by turning off the VPN switch or fully uninstalling the Extension from your Chrome browser.
