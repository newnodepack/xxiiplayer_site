🔒 Privacy Policy

IlbonVPN Extension  |  Last updated: May 2025

📋 1. Overview

This Privacy Policy describes how the IlbonVPN Extension ("Extension", "we", "our") handles user data. This Extension is a Chrome browser extension that allows authenticated users to connect to a private HTTP proxy server using their account credentials.

We are committed to protecting your privacy. This policy explains exactly what data is collected, why it is collected, and how it is handled.

We collect only the minimum data necessary to provide the Extension's core functionality.

⚙️ 3. How We Use Your Data

  • Email address & Firebase UID — Used solely to authenticate the user and determine access to premium proxy servers. Not used for marketing or analytics.
  • Session token — Generated server-side after successful Firebase token verification. Used to authorize proxy connections. Automatically deleted from server memory after 1 hour.
  • Connection state (local) — Stored on the user's device only via chrome.storage.local. Used to restore the popup UI state. Never transmitted externally.

🚫 4. Data We Do NOT Collect

The following data is never collected, stored, or transmitted by this Extension:

Browsing history Visited URLs Web page content Keystrokes / form input Location data Financial information Health information Device identifiers Cookies from other sites
⚠️ Note on Proxy Traffic Although web traffic is routed through our proxy server when the Extension is active, we do not log, store, inspect, or analyze the content of any proxied requests. Traffic is forwarded as-is and no records are retained.

🛡️ 8. Security

  • All authentication is handled by Firebase Authentication, which provides industry-standard security including secure token issuance and verification.
  • Firebase ID Tokens are verified server-side using Google's public JWKS endpoint before any proxy access is granted.
  • Session tokens are stored in server memory only and are never written to disk or database.
  • All SDK files (Firebase, Bootstrap) are bundled locally within the extension. No external scripts are loaded at runtime.
  • This extension does not use eval(), dynamic script injection, or any form of remote code execution.

👤 9. Your Rights

You have the right to:

  • Access — Request information about what data we hold about you.
  • Deletion — Delete your account at any time via the Account page in the Extension. This removes your Firebase credentials permanently.
  • Opt-out — Simply disconnect the proxy and uninstall the Extension at any time. No data persists after uninstallation.
